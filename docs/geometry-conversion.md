# Source geometry preservation

转换以完整源中间平面为起点，同一围护结构两侧使用相同几何；不因平面凹性或共线点就统一细分，也不合并属于不同源对象、房间、构造或边界的面。接地面、区间面和无局部裁剪约束的水平屋顶优先保留整面。凹水平屋顶只在边界与向上延伸的外墙共享正长度源边段时保留局部凸分解；不因低于全楼最高点、远处高墙、单点接触或存在活动遮阳就切分。正式多边形裁剪消费者还包括外露投影面和开口宿主。局部关系按源平面容差`1e-8 m`判断，不吸附邻近坐标。这是源几何兼容规则，不枚举全部潜在投影关系，也不计算遮挡量或日照比例；非相接物体对凹屋顶的实际遮阳适用性仍需结合EnergyPlus的原生几何诊断确认，不能声称所有凹接收面的遮阳算法均等价。实际遮阳由EnergyPlus处理。

空间上相近不构成共享顶点的依据。源中间平面/顶点索引确定两侧共同坐标；不再对全模型做厘米级近邻吸附。共享副本不一致、非平面、自交、清理导致源面面积损失或整面消失时明确报错，不通过移动无关面的顶点修复。

仅在清理后的源几何边检查实际失败时试验局部切分；共享面同步处理另一侧，完成后尝试撤销临时切分、恢复整面。源容差检查仍执行相同的顶点清理，但用`1e-8 m`区分不同边；EnergyPlus体积诊断另用`1 cm`容差。源壳已闭合而宽容差误将相近边混同的情况，保留原面并发出`destep_geometry_closure_tolerance`警告，不为消除警告切完整房间，也不宣称原生闭合检查全部通过。真正清理缺口无法可靠表达时明确失败，不静默输出另一套边界。`attr(idf, "conversion")$surface_geometry`记录源面ID、源中间平面、目标名称、房间、构造、边界、配对引用、面积与顶点数，供逐对象核对。

窗裁片按源对象逐侧检查面积保留；部分越界、过窄裁片丢失或异常重复覆盖不再以“还有一片窗存在”为通过条件。错误包含源窗ID和输入/输出面积，几何无法可靠表达时需要修正源输入或宿主划分，不自动裁小窗户。面积守卫以非重叠的源面分区为前提；几何回归另行检查分片并集、重叠和源归属。
