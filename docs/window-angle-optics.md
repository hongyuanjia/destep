# 源窗角度光学

有效 `WINDOW.TYPE > 0`、`WINDOW_TYPE_DATA.LAYER_NUM = 2`，且两侧黑度能用于详细玻璃对象时，转换器使用源 SC 恢复 0—90°、每 1°的太阳透射率与反射率。它保留 DeST 的折射指数搜索、30°以下的法向反射分支和90°的零透射端点，不通过年度负荷或规范参考窗拟合 SC。

目标采用 `WindowMaterial:Glazing` 的 `SpectralAndAngle` 和三张 `Table:Lookup`。角度是第一个独立变量，波长是第二个，后者在输出数组中变化最快。因此每个角度值依次在 0.1、4 μm 重复。正反向材料共享光学表，并继续交换各自的内外侧红外黑度；热阻、窗口行 K、厚度、几何及母墙扣洞规则不因此改变。

两轴的 `Unit Type` 元数据统一使用 `Dimensionless`，角度数值仍是0—90度。EnergyPlus 9.2、23.1的实际曲线读取器会用输出单位列表检查独立轴，从而拒绝IDD允许的 `Angle`；窗口模块直接以度数查询角表，曲线模块不根据这项元数据换算坐标。因此该设置用于跨版本运行兼容，不改变源角度、表值或窗口计算的查询坐标。IDD检查通过还需要配合实际引擎启动检查。

实际需要详细 N2 角表的模型要求 EnergyPlus 9.2 或更新版本。请求更旧版本会明确报错，不静默恢复成只有法向值的表示。没有该有效源分支的模型仍按其其他功能选择生成版本。N1、负 TYPE、其他层数及缺少可用黑度的聚合分支没有在此次修改中扩大适用范围。

这项功能改善的是源输入保留，不保证两个引擎的窗得热或制冷峰值相同。仍有以下适用边界：

- 源数据没有物理光谱，两个波长复制使用灰色光谱近似；背面反射继续采用与正面相同的曲线，不能将其称为已恢复的原生背面光学。
- EnergyPlus 对角表实施自己的角度多项式处理和半球漫射积分，DeST 已确认的漫射分支采用固定60°。源曲线写入目标输入，不意味着每个实际入射角的运行透射值完全等于表值。
- 等效单层窗仍不保留 DeST 外侧吸收热源的落点、室内返回短波热源节点和玻璃容量。多层窗及净热源替换实验没有成为默认转换规则。
- 已确认在此原生分支不参与计算的保存可见光字段继续只作源元数据，不赋予新的目标含义。
