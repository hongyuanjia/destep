# 转换输入、近似和响应边界

正式包只提供原有直接等效窗表达（研究记录中的`equivalent`），不再要求用户选择窗算法。转换不进行窗光学预运行，不生成天气绑定的窗净热源文件，也不依赖外部脚本、插件或DeST结果回放。其它默认配置保持不变。

destep以可信的模型输入转换为目标。几何/归属、有效日程、得热总量与物性需要独立核查；EnergyPlus运行成功不等于DeST逐时响应等价。转换遗漏、已声明的表示近似和引擎算法差异分别记录，不用输出拟合代替输入修正。

|内容|目标表示与边界|
|---|---|
|几何、表面归属、扣洞、面积与体积|保留源关系并执行相应检查；唯一宿主依据允许恢复冗余归属，歧义拒绝。共享房间组不增加原生合并逻辑。|
|不透明物性与得热|使用物理层及有效日程；总得热、对流/辐射分量与逐面分配分别解释。已有支持范围外的设备/关系继续诊断。|
|正TYPE两层窗，输入完整且两侧黑度均大于0|采用6mm等效普通玻璃，导热率表达`max(1/type_U-.157861,1e-6)/row_K`热阻；保留有序内外黑度及SC恢复的0—90°太阳τ/ρ角度表。可见τ采用原生采光共用的SC恢复值，可见ρ采用同栈值的灰体对称近似。保存的LIGHT_TRANS_RATIO/LIGHT_REFLECT_RATIO不被已核实原生分支消费，不作为资格门槛或有效目标光学。等效厚度不是恢复的物理玻璃栈。|
|其它合法窗类型或未满足已核实热工条件|采用明确的SimpleGlazing近似；行K修正材料热阻，不放大几何、扣洞面积或窗乘数。正TYPE N2即使退回简化表示，仍使用原生`max(1/type_U-.157861,1e-6)/row_K`热阻及SC恢复的可见τ。零黑度保留聚合近似及未表达黑度诊断；其它分支的可见表达未完成原生验证。非法有效行K拒绝；两层已选窗的非法/无法解析黑度拒绝。缺失闲置可见字段不会拒绝有效K/SC窗型；缺失或非法的有效K/SC仍拒绝，不以另一玻璃栈静默替代。|
|角度、漫射和背面光学|详细N2等效普通玻璃使用源角度表，目标进行角度插值/多项式及半球漫射积分，背面反射率假定等于前面；源固定60°漫射诊断保留，不伪称已经应用。|
|采光室内反射|原生正TYPE采光使用SC派生窗透射，但室内多次反射使用独立的固定面积加权规则。目标可见ρ的灰体表达不等同复现该规则，也不表示已支持完整采光或照明调光转换。|
|太阳与内部辐射热源接收面分配|采用EnergyPlus算法。太阳模式、保存权重、缺失引用及源接收面元数据保存在`attr(idf, "conversion")$solar`；没有注入额外热源、将窗热搬到空气或自动归一原生权重。|
|窗吸收节点和热容|普通窗没有复现DeST外节点吸收位置及两节点容量。独立CTF研究面仅用于机制验证，不作为真实窗生产替代。|
|天空辐射和瞬态状态|目标引擎正常求解。受控等温天空试验的边界处理不推广为一般天气的默认补偿；不平移负荷时间轴或拟合源负荷。|
|小时积分、热源历史与控制负荷|已核实的DeST DPE 2023年分支采用小时模态响应和热源历史；控制补偿有独立一步响应。EnergyPlus采用自身的细步热平衡/控制和输出统计。原生逐小时控制负荷与目标小时平均或系统步负荷不能直接假定相同；峰值幅度和达峰小时均不承诺一致。|

`conversion$windows`按每扇窗保留type K、row K、SC、有效热阻、黑度、目标表示、恢复光学及未表达项。`conversion$solar`包含源窗模式绑定、四个保存权重与表面权重和；它们是权重，不是已经求出的百分比分配。接收面表只记录保存的原始归属/面积，shared_group记录不表示已经支持原生共享组动态。

保存IDF后，材料与Version注释仍记录源参数和限制；R属性本身不会随IDF重载恢复。`conversion$simulation$response`记录目标实际区域步长和小时响应边界，不更改控制、输出频率或时间轴。有效目标对象、输入保留和响应比较必须分别验收。

审计中的原生时间步字段描述经核实的2023年分支参照，不表示已经读取并验证任意其它DeST版本的实际求解时间步。

## 可修正的遗漏

本轮修正对应已核实源输入：窗口行K和有序两侧黑度不能被按房型合并而丢弃；原生正TYPE两层窗消费SC派生光学，保存可见字段不得成为详细窗的错误资格门槛。目标退回简化表示也不能改变这个源分支的有效热阻公式。源保存值和有效目标值分别保留，原始数据库不改写。

已验证的正TYPE N2角度曲线现写入正式窗对象，使用0—90°每1°的源SC恢复透射/反射表，保留30°分支与90°端点。有效详细N2窗要求目标版本至少9.2；其他分支不扩大适用范围。目标仍处理角度插值/多项式及半球漫射积分，原生漫射分支使用固定60°值；灰色光谱和对称背反射继续属于近似。不能因为负荷残差存在就声称已排除这些影响，也不能通过任意调整SC抹平它们。详见[源窗角度光学](window-angle-optics.md)。

## 已声明的近似与引擎差异

太阳和内部辐射接收面分配保留目标算法，源权重是审计信息，不表示已经应用。普通窗的吸收节点和玻璃容量也未复刻；CTF研究替代物没有进入生产模型。这些表示近似和目标窗口热平衡算法的区别同时存在，不能把“已声明”理解为“数值影响可以忽略”。

人员、照明和设备的有效功率、日程、照明散热比例及对流/辐射/潜热份额仍由转换器负责正确映射，不因空间分配近似而省略。源接收面族系数没有与目标算法一一对应的通用表达，因此仅保留供审计；不将保存系数称为已经应用，也不为复刻它们另算遮挡、拟合负荷或重复注入太阳。当前生成模型沿用EnergyPlus的`FullExterior`，不是`FullInteriorAndExterior`；不未经验证切换其室内直射追踪方式。

DeST每个小时使用有历史的自由响应和一步控制响应求解补偿量，结果直接写出；EnergyPlus可在小时内部多次求解补偿量，并对平均型负荷率作时间加权小时平均。即使两者小时室温相同，也不能推定小时内状态和控制功率相同。对相同开环线性系统，线性源节点响应与保持源小时平均响应可以相等；这一性质不能推广为完整受控房间等价，也不能单凭积分系数把所有峰值错位归因于时间取值。

原生小时索引、源太阳几何取值时刻和EnergyPlus区间结束标签应分别登记。DeST显热结果的kW及制冷负号必须转换后才与目标W比较。房间显热、原生新风显热、理想负荷区域端或供风端分别配对；模型峰值取逐小时同时负荷之和的最大值，不能把不同房间各自峰值相加。不默认平移一小时，不选择最接近原生峰值的报告频率来宣布等价。

## 全年验证和用途

工程响应分别报告累计负荷、峰值幅度与时刻、逐时曲线和一阶差分误差，并给出源、天气、引擎、计算步长和输出定义。温度、自由浮动案例和已有失败案例另列；缺失或零分母不补零、也不计入相对误差范围。对相同输入的前后比较，应保留实际对象顺序及已登记运行条件，区别物理字段改变、注释改变和数值序列化敏感性。

验证合格意味着本轮输入保留、目标有效性和登记的响应检查通过，不意味着完整ASHRAE 140合格或所有DeST结果等价。当前工程验收限定为统一天气、运行条件和统计口径下，长春、天津、海口办公原型的全年累计冷、热负荷分别相对DeST不超过±10%，六项独立判断；12个标准案例保留三方比较，整体与reference相当即可，不要求逐项更好。该门槛只适用于这组案例，不作为所有模型的通用容差。不要求跨引擎峰值和达峰小时完全一致；所有尚未归因的偏差继续保留，不能自动归类为引擎差异或以冷热相抵豁免。

只有发现明确、可修正的输入遗漏时才修改转换表达，并按实际计算输入差异重跑受影响模型。保留已确认正确的窗光学、有效热阻及共享墙，不以错误相互抵消追求达标。若限定范围内修正后仍未达标，报告具体项目和证据，由维护者决定是否扩大研究；不无限扩展归因，不要求残差归零。历史研究窗的较好结果不能作为正式直接路径已经达标的证据。

### 当前直接路径的验证状态（2026-10-18）

以下历史结果对应几何、窗和状态控制共同应用的本地实现，不是单独窗分支的验证结果。相关修正尚未共同合入时，不能据此宣称单独分支已达到这些数值。

窗接口收敛前后15份实际IDF的计算字段一致。12个标准案例与已保留默认生成图也相同，复用其统一源天气三方结果；三地办公原型因最近几何修复改变实际输入，本次重新完成全年计算。原型采用显式IdealLoads、standard通风密度、temperature_feedback人员显热和outdoor_band通风控制，不等于所有API默认参数组合。原型没有独立reference IDF，不能虚构第三组结果。

|城市|累计供热偏差|累计制冷偏差|六项独立验收|
|---|---:|---:|---|
|长春|+6.15%|−5.25%|两项通过|
|天津|+12.23%|−2.24%|供热未通过|
|海口|+2.17%|+5.16%|两项通过|

天津供热为DeST 571.478 MWh、转换后641.382 MWh，差+69.904 MWh；仍未达到±10%。其余5项通过不抵消该项。海口供热为DeST 10.596 MWh、转换后10.826 MWh，绝对差仅+0.230 MWh。

12个标准案例逐例对DeST绝对累计误差之和，供热为转换后2764.9 kWh、reference 2523.3 kWh，制冷为转换后5494.5 kWh、reference 2089.8 kWh。供热7/12（含零值持平）、制冷1/12不差于reference。这是当前直接路径的结果，不能声称它已取得退役研究路径的精度，或已证明整体与reference相当。未解释残差保留，不整体归因于算法。这些数值仅描述上述固定输入和配置，不是所有模型的精度保证。软件范围收敛完成不等于累计负荷全部验收通过。

保存可见原值由`SOURCE_LIGHT_TRANS_RATIO`、`SOURCE_LIGHT_REFLECT_RATIO`记录；`SOURCE_VISIBLE_USAGE`区分已核实不消费的N2分支和其它未核实分支，`NORMAL_VISIBLE_TAU/RHO`记录SC恢复值。若仍采用SimpleGlazing，仅显式写入可见τ，记录的可见ρ是未应用的原生诊断值。缺失原值保持缺失，不补零或归一化。其余热工资格及非法有效参数拒绝规则保持。

原生核验范围是DPE 2023年7月构建；反编译地址包括正常SC光学`18015cac0/18015bd90`、小时系数`18005ba40`、控制一步响应`18005b440`及显热写表`1802d9c70`。二进制SHA256为`10a5ee8151b0dbda9792b4de383df88169d1cc0b57ea12ed200198cf4f86f747`。这些身份限定证据范围，不声称覆盖所有DeST版本。
